Closes #3027

This PR updates `.github/workflows/e2e-segmented.yml` to prevent E2E runs on `main` from being cancelled by utilizing `${{ github.sha }}` for the concurrency group, while introducing a `pull_request` trigger with path filtering for Rust sources.

The workflow is now configured to run only the `e2e-01` job (smoke segment) on pull requests to ensure regressions are caught before merge, while preserving the full matrix on `main`. The final `gate` job has been updated to handle skipped jobs without failing, and includes inline bash self-tests.
