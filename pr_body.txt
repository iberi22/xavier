Closes #3013

### What Changed
- Removed the `continue-on-error: true` override from the `rust-test-hygiene` job in `.github/workflows/ci.yml`. This makes the static audit (`Audit every test/bench root installs the sandbox`) blocking, so missing the `isolate_test_process!` macro will properly fail the CI pipeline.
- Added `continue-on-error: true` explicitly to the slow snapshot subset step (`Check no test writes to the real home`), preserving its advisory nature.
- Added a `test(audit)` step just before the real audit to prove the static verification logic correctly catches a dynamically-generated dummy test file missing the macro.

### Why
By keeping the snapshot subset as advisory, we ensure environmental flakes do not block `main`, while simultaneously tightening the loop on the static macro audit to prevent any drift in integration tests. The new test step demonstrates that if the `isolate_test_process!` macro is forgotten, the job will fail.
