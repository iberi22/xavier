## Plugin System — F1 (Foundation) + F2 (Engine + Fallback)

Scope locked: core engine + fallback chain + all bug fixes. No network/archive/heavy-dep work (that's F3-F4, deferred). Completes T-13 and T-14 (the two 🔴 ALTA tasks). Storage uses platform-native dirs via the already-present `dirs` crate.

### What gets built

**Phase 1 — Foundation**
1. **`types.rs`** — Extend `Language` enum:
   - Add `Other(String)` variant (payload for dynamically-discovered languages)
   - Add `fn as_str(&self) -> &str` returning `"rust"`, `"python"`, ..., `"other"` — a stable identifier for **DB persistence and API output**, NOT `Debug` format
   - `from_extension()` unchanged for now (keeps returning `Unknown` for unknown exts — fixes the indexer file-discovery guard issue from the hermes "BUG #2" line)
2. **`db/mod.rs`** — Fix silent data-loss round-trip:
   - Rewrite `parse_language()` to handle `Other(s)` form: recognize `"other:<lang>` strings produced by a new `as_db_str()` helper, fall back to existing `serde_json` path for backward-compat with existing rows (`"Rust"`, `"Python"`, etc.)
   - Swap write sites (lines ~321, 379, 645) from `format!("{:?}", lang)` → new stable identifier helper
   - Update the `parse_language` test to cover `Other("ruby")` round-trip
3. **`mcp/context_builder.rs:49`** — Fix the hard compile break: add `Language::Other(_) | Language::Unknown => ""` arm to the highlight-language match
4. **`plugin/types.rs`** (new) — Core abstractions, no deps:
   - `PluginDescriptor { name, version, command, languages, capabilities }`
   - `FallbackStep` enum: `Plugin(String)`, `Native`, `NoOp`
   - `PluginHealth` (simple: `success_count`, `failure_count`, last error) — minimal, no ring buffer yet
   - `PluginConfig`, `PluginRequest`/`PluginResponse`/`FileToParse` — **moved** from `plugin_host.rs` (these are reused)
5. **`plugin/mod.rs`** (new) — Module re-exports + `PluginManager` skeleton struct (fields only + `new()`)

**Phase 2 — Engine + Fallback**
6. **`plugin/engine.rs`** (new) — `ProcessEngine`:
   - Port `parse_with_plugin()` logic from `plugin_host.rs`
   - Configurable timeout (default 30s per spec, was 5s)
   - `kill_on_drop`, stdin/stdout JSON protocol
7. **`plugin/fallback.rs`** (new) — `FallbackChain`:
   - `per_language: HashMap<Language, Vec<FallbackStep>>`
   - `default_for(lang)` → `[Plugin(name), Native, NoOp]` if a plugin is installed for the lang, else `[Native, NoOp]`
   - Load/persist to `<config_dir>/code-graph/fallback.json` (best-effort; missing file = use defaults)
8. **`parser/mod.rs`** — Rewrite `parse_source()`:
   - New signature: `parse_source(source, lang, file_path, plugin_manager: Option<&PluginManager>)`
   - Iterate `FallbackChain` steps: try each, log `warn!` on each failure, return first success, `NoOp` → empty `Vec<Symbol>` (never crashes)
   - **Fix the duplicate match arms** (Python + TypeScript appear twice, lines 82-89) — delete the dead second copies
   - Keep the existing 7 native parsers working unchanged
9. **`plugin_host.rs`** — Convert to backward-compat shim:
   - `#[deprecated(note = "Use PluginManager")]`
   - `PluginHost` becomes a thin wrapper holding an `Arc<PluginManager>`
   - `parser_for()` / `parse_with_plugin()` delegate to PluginManager
   - **Fix bug #1**: remove the `if *lang == Language::Rust { return Native; }` hardcode at line 91 — Rust now goes through the fallback chain like everything else
10. **`indexer/mod.rs`** — Minimal: keep `plugin_host: Arc<PluginHost>` field (still works as deprecated wrapper). No signature changes needed — backward compat holds.

**Phase 3 — Verify**
- `cargo build --release` clean (zero warnings added beyond existing baseline's 5)
- `cargo test` — existing 6 parser tests + 5 indexer tests + new `parse_language` Other() round-trip test + a fallback-chain unit test must pass
- Manual smoke check that `Language::Rust` still routes to native parser after removing the hardcode
