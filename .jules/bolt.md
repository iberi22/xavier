## 2024-05-18 - [Extracting inline JSX in mapping to memoized components]
**Learning:** In React components like `FounderNodeStatusCard`, if `telemetry.peers` is populated by periodic updates (e.g., fetching new data every 15 seconds), each `peer` item in the array is often a completely new object reference. Because `React.memo` uses a shallow comparison by default, it will see the new object reference, determine the props have changed, and re-render the component anyway, negating the optimization and degrading performance.
**Action:** When extracting mapped elements into `React.memo` components, provide a custom `areEqual` comparison function as the second argument to `React.memo` that explicitly compares the object properties, or destructure the object and pass down primitive values as props.
