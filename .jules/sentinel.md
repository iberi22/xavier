## 2024-05-24 - [Path Traversal in Training Routes]
**Vulnerability:** Path traversal vulnerability in `src/server/training_routes.rs` handlers where the `id` path parameter was directly joined with `state.data_dir` without validation.
**Learning:** Axum routes using dynamic path parameters (like `{id}`) must not be directly joined to base directory paths (`state.data_dir.join(&id)`) without prior validation, as this allows attackers to use URL-encoded relative path segments (e.g., `..%2f`) to escape the intended directory and access arbitrary files.
**Prevention:** Always implement a strict allowlist validation function (e.g., verifying `id` only contains alphanumeric characters, periods, underscores, and hyphens) and validate the path parameter *before* any path concatenation or `join` operations occur.
