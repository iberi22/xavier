# PageIndex end-to-end harness

Reproduces the real-PDF evaluation reported in ADR-036 and
`docs/features/specs/FEATURE-pageindex-tree-retrieval.md` ("End-to-end evaluation (real PDFs)").
Nothing here is downloaded or generated by the repo: the benchmark data, answers, logs and
tokens stay outside version control.

## Prerequisites

- A xavier build with the `pageindex` features (`pdf-outline` and `pdf-layout`) and a pdfium
  shared library (`libpdfium`, binaries matching the `pdfium_6996` binding).
- Python 3 (stdlib only).

## 1. Fetch the public benchmark

```bash
git clone https://github.com/VectifyAI/PageIndex-OSS-Benchmark "$HOME/pageindex-bench"
```

Use its PDFs directory as `BENCH_DOCS` and its questions file as `BENCH_QUESTIONS`
(62 lookup questions, 34 PDFs, 1,945 pages). The scripts read the fields `doc_id`, `question`,
`answer` and `evidence_pages` (a JSON-encoded list of page numbers) of each question; adapt
the paths if the upstream layout differs.

## 2. Start an isolated instance

```bash
export XAVIER_BIN=/path/to/xavier XAVIER_TOKEN=$(openssl rand -hex 24)
export BENCH_DOCS=$HOME/pageindex-bench/documents PDFIUM_LIB_DIR=/path/to/pdfium/lib
./run-server.sh &
```

## 3. Ingest, baseline, navigate, score

```bash
./ingest.py "$BENCH_DOCS"                                   # writes ingest_results.json
./bm25_baseline.py "$BENCH_QUESTIONS" ingest_results.json   # page-level BM25 hit@1/3/5 (no LLM)
```

Navigation: give each agent `nav_protocol.md` plus a batch of questions (without the answer
key). The agent calls `./pi.py <tool> '<json>'` with `PI_LOG=nav_logs/q<qid>.jsonl` set, and
writes `nav_answers_<batch>.json`. Then score (orchestrator only):

```bash
./score.py "$BENCH_QUESTIONS"    # writes nav_scores.json; correctness still needs manual review
```

`pi.py` reads `PI_URL` (default `http://127.0.0.1:18006/mcp/tools/call`) and the token from
`XAVIER_TOKEN` or `PI_TOKEN_FILE`. Outputs (`ingest_results.json`, `pages_cache.json`,
`bm25_results.json`, `nav_*`, `work/`) are git-ignored; do not commit them.

## Caveats

The published numbers use a single run per round and a manual judge; see the spec for the
full setup.
