Enrolment files for Anthropic's OSS Scanner (https://github.com/anthropics/oss-scanner).

- Dockerfile: builds /src with network (cargo fetch, debug build, test --no-run) so the scanner
  can build and run tests with no network. Default features; panel-ui (TypeScript) out of scope.
- threat_model.md: generated by kernel-security-memory scripts/oss_scanner/threat_model.py from
  ksm-context.yaml (human-written) plus KSM evidence. Do not edit it by hand; edit the context and
  regenerate (`--check` detects drift).

Verify like the scanner: clone, delete .dockerignore, `docker build -f .oss-scanner/Dockerfile .`,
then `docker run --rm --network none <image> bash -lc 'cd /src && cargo build --offline'`.
