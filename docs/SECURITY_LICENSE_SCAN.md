## 4. Recommendations

### Priority (Low/Medium)

1. **Patch lru to ≥0.13** — The unsound `IterMut` issue is low-risk in practice (Xavier uses `moka` as its primary cache; `lru` is transitive), but it's UB and worth resolving.
2. **Replace bincode** (transitive via burn/gllm) — Since `gllm` is behind the optional `local-gllm` feature, the risk is contained. If `local-gllm` is used, consider upstream pinning or alternatives.
3. **Upgrade rustls-pemfile** — Already at latest v1.x; the fix is in v2.x. Transitive via TLS stack; not directly imported by Xavier.

### Nice-to-Have

4. **Install cargo-deny** for CI pipeline (`cargo install cargo-deny`) — enables automated license + ban + advisory checks in CI
5. **Install cargo-outdated** for regular dependency freshness reports (`cargo install cargo-outdated`)
6. **Add cargo-audit to CI** — run `cargo audit` on every PR to catch new advisories early
