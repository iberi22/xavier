# ISSUE: Onboarding v2 — Advanced System Detection + Interactive Setup

**Type**: feature | **Labels**: backend, onboarding, UX | **Priority**: P0 | **Points**: 5

## Context
El onboarding actual detecta OS, Docker, y herramientas básicas. Debe ser v2 para detectar todo el ecosistema LLM y guiar al usuario a configurar Xavier óptimamente.

## Scan at Startup
Al ejecutar `xavier setup`:
1. Correr SystemScanner (Issue 1.1)
2. Mostrar resumen:
```

🎮 GPU: AMD Radeon RX 6600 (8GB VRAM)
🦙 Ollama: RUNNING (gemma-4-e2b-q4, nomic-embed-text)
🧰 CLI Agents: opencode ✓ | codex ✓ | claude ✓ | copilot ✗
🔑 API Keys: OpenAI ✓ | Gemini ✓ | Groq ✓ | Firecrawl ✓
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```
3. Preguntas interactivas (ver FEATURE spec completo)

## Persistent Config
Guardar en `~/.xavier/provider-config.yaml`:
```yaml
active_provider: auto
auto_strategy: lowest_latency
fallback_chain: [claude, openai, groq]
headless:
  enabled: true
  port: 8007
  auth_token: "<generated>"
notifications:
  provider_limit_warning: true
  new_model_detected: true
  better_provider_available: true
```
