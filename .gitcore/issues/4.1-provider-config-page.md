# ISSUE: Provider Settings Page — React/Tauri UI

**Type**: feature | **Labels**: frontend, react, panel-ui | **Priority**: P0 | **Points**: 8

## Context
El nuevo UI de Xavier (panel-ui, React + Tauri + Radix UI) necesita una página de configuración de proveedores LLM con detección, login status, quotas, y cambios.

## UI Components

### ProviderSelector
- Dropdown con proveedores detectados
- Indicador: 🟢 Running / 🟡 Degraded / 🔴 Error
- Botón "Switch" para cambio en caliente

### CliAgentList
- Cards por CLI agent detectado
- Status: 🟢 Logged in / 🟡 Not logged in / ⚪ Not installed
- Toggle enable/disable
- Botón "Login" que intenta auth automático

### QuotaTable
| Provider | Tier | Requests | Tokens | Reset | Status |
|----------|------|----------|--------|-------|--------|
| OpenAI   | Free | 3.2K/5K  | 42K/100K | 2h  | 🟡    |
| Anthropic| Pro  | ∞        | 120K/∞  | —    | 🟢    |

### ApiKeyInput
- Input con máscara
- Botones Show/Hide, Test Connection, Remove

### HeadlessToggle
- Switch on/off
- Puerto configurable

## API Endpoints
```
GET  /v1/system/scan       → SystemScan
GET  /v1/providers/quota   → ProviderQuota[]
PUT  /v1/config/providers  → update config
GET  /v1/config/providers  → current config
POST /v1/providers/:name/test → test connection
```
