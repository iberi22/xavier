# ISSUE: CLI Agent, Model & Service Discovery (SystemScanner)

**Type**: feature | **Labels**: backend, detection, system | **Priority**: P0 | **Points**: 5

## Context
Xavier necesita escanear el sistema al inicio para detectar todos los proveedores de LLM disponibles: CLI agents instalados, modelos Ollama, GPU, env vars de API keys, config files, y estado de login.

## What to detect

### CLI Agents
| Agent | Detection | Version cmd | Login check |
|-------|-----------|-------------|-------------|
| opencode | npm global | `opencode --version` | `env OPENAI_API_KEY` |
| codex | npm global | `codex --version` | `codex login status` |
| claude | standalone | `claude --version` | `~/.claude/.credentials.json` |
| copilot | npm global | `copilot --version` | `~/.copilot/config.json` |

### Ollama
- Via `curl http://localhost:11434/api/tags` → lista de modelos
- Si el servicio no corre, reportar "Ollama not running"

### GPU
- Windows: dxdiag → Modelo, VRAM total (confirmar con dxdiag, WMI miente), driver
- Linux: nvidia-smi o rocm-smi

### Env Vars
OPENAI_API_KEY, ANTHROPIC_API_KEY, GEMINI_API_KEY (x4), GROQ_API_KEY, MINIMAX_API_KEY, DEEPSEEK_API_KEY, OPENROUTER_API_KEY, FIRECRAWL_API_KEY

### Config Files
- `~/.claude/settings.json` → qué modelo usa, endpoint
- `~/.copilot/` → session, config.json
- `~/.codex/` → login tokens
- `~/.xavier/` → la propia config de Xavier

## CLI Commands
- `xavier system scan` → imprime reporte completo
- `xavier system scan --json` → output JSON para API

## Implementation notes
- Usar `std::process::Command` para CLI agents
- Para Ollama: HTTP request a `localhost:11434`, timeout 2s
- Para GPU: `Get-CimInstance` en Windows, `nvidia-smi` en Linux
- No bloquear startup si algún servicio no responde (timeout + skip)
- Cachear resultados por 60 segundos
