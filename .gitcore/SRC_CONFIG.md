## 2. Configuration Files

### Core Runtime Configuration
- **Location:** `config/xavier.config.json`
- **Purpose:** Primary configuration for the Xavier server, memory layers, and model providers.
- **Key Sections:**
    - `server`: Host, port, and log level.
    - `workspace`: Multi-tenant settings and limits.
    - `memory`: Backend (vec/sqlite), data directories, and dimensions.
    - `memory_layers`: Parameters for working and episodic memory.
    - `models`: LLM and Embedding provider settings (Local/Cloud).
    - `retrieval`: Learned policy weights and search multipliers.
    - `sync`: Intervals and thresholds for data synchronization.
    - `data_commons`: Governance and data sharing settings.

### Environment Variables
- `XAVIER_TOKEN`: Authentication token for the HTTP API (Required for production).
- `XAVIER_CONFIG_PATH`: Override path for the configuration JSON.
- `XAVIER_CODE_GRAPH_DB_PATH`: Path to the code-graph sidecar database.

## 3. Module Requirements (src/)

### Agents (`src/agents/`)
- **Requirements:**
    - Active LLM provider (Ollama, OpenAI, or Gemini).
    - Access to memory storage for System 2/3 reasoning.

### Memory (`src/memory/`)
- **Requirements:**
    - SQLite with `sqlite-vec` extension (or bundled via `rusqlite`).
    - Valid embedding model for vector generation.

### Mesh (`src/mesh/`)
- **Requirements:**
    - Ed25519 identity keys (auto-generated in `~/.config/xavier/`).
    - P2P connectivity for mesh synchronization.
